# RWX Docs

Official documentation site for [RWX](https://github.com/eam2539/RWX).

- Live site: <https://rwx-docs.netlify.app>
- Stack: VitePress + Mermaid
- Locales: English (root) and 简体中文 (`/zh`)

## Develop

```bash
npm install
npm run docs:dev
```

## Build

```bash
npm run docs:build
```

Output is written to `docs/.vitepress/dist` (see `netlify.toml`).
